# Render Deployment Guide for PMC Backend

This guide will help you deploy your Django backend to Render.

## Prerequisites

1. A Render account (https://render.com)
2. Your code pushed to a Git repository (GitHub, GitLab, or Bitbucket)

## Deployment Steps

### Option 1: Using render.yaml (Recommended)

1. **Push your code to Git**
   ```bash
   git add .
   git commit -m "Add Render deployment configuration"
   git push origin main
   ```

2. **Deploy on Render**
   - Go to https://dashboard.render.com
   - Click "New +" and select "Blueprint"
   - Connect your Git repository
   - Render will automatically detect the `render.yaml` file
   - Click "Apply" to start the deployment

3. **Set Environment Variables**
   After deployment, go to your service settings and add these environment variables:
   - `SECRET_KEY`: Generate a new secret key (Render can auto-generate this)
   - `ALLOWED_HOSTS`: Your Render URL (e.g., `pmc-backend.onrender.com`)
   - `CORS_ALLOWED_ORIGIN_REGEXES`: Your frontend URL

### Option 2: Manual Setup

1. **Create a PostgreSQL Database**
   - Go to https://dashboard.render.com
   - Click "New +" and select "PostgreSQL"
   - Name: `pmc-db`
   - Database: `pmc_db`
   - User: `postgres`
   - Plan: Free
   - Click "Create Database"
   - Note the internal database URL

2. **Create a Web Service**
   - Click "New +" and select "Web Service"
   - Connect your Git repository
   - Configure the service:
     - **Name**: `pmc-backend`
     - **Runtime**: Docker
     - **Build Command**: `docker build -t pmc-backend .`
     - **Start Command**: `gunicorn backend.wsgi:application --bind 0.0.0.0:8000 --workers 3 --timeout 120`
     - **Plan**: Free

3. **Add Environment Variables**
   In your web service settings, add these environment variables:
   ```
   SECRET_KEY=<your-secret-key>
   DEBUG=False
   ALLOWED_HOSTS=.onrender.com
   USE_POSTGRESQL=True
   DB_NAME=pmc_db
   DB_USER=<from-database>
   DB_PASSWORD=<from-database>
   DB_HOST=<from-database>
   DB_PORT=5432
   CORS_ALLOW_ALL_ORIGINS=False
   CORS_ALLOW_CREDENTIALS=True
   CSRF_COOKIE_SECURE=True
   CSRF_COOKIE_HTTPONLY=False
   CSRF_USE_SESSIONS=False
   ```

4. **Deploy**
   - Click "Create Web Service"
   - Render will build and deploy your application

## Post-Deployment

### Automatic Setup
The deployment automatically:
- Runs database migrations
- Collects static files
- Creates a superuser (if configured)

### Superuser Credentials
The superuser is automatically created with these environment variables:
- `DJANGO_SUPERUSER_USERNAME`: admin (default)
- `DJANGO_SUPERUSER_EMAIL`: admin@example.com (default)
- `DJANGO_SUPERUSER_PASSWORD`: Auto-generated by Render

To view the auto-generated password:
1. Go to your web service in Render dashboard
2. Click on "Environment" tab
3. Find `DJANGO_SUPERUSER_PASSWORD`

### Manual Superuser Creation
If you need to create additional superusers:

1. Go to your web service in Render dashboard
2. Click on "Shell" tab
3. Run:
   ```bash
   python manage.py createsuperuser
   ```

### Collect Static Files
Static files are automatically collected during the Docker build process.

## Environment Variables Reference

| Variable | Description | Example |
|----------|-------------|---------|
| `SECRET_KEY` | Django secret key | Auto-generated by Render |
| `DEBUG` | Debug mode | `False` |
| `ALLOWED_HOSTS` | Allowed hostnames | `.onrender.com` |
| `USE_POSTGRESQL` | Use PostgreSQL | `True` |
| `DB_NAME` | Database name | `pmc_db` |
| `DB_USER` | Database user | `postgres` |
| `DB_PASSWORD` | Database password | From Render dashboard |
| `DB_HOST` | Database host | From Render dashboard |
| `DB_PORT` | Database port | `5432` |
| `CORS_ALLOW_ALL_ORIGINS` | Allow all CORS origins | `False` |
| `CORS_ALLOW_CREDENTIALS` | Allow CORS credentials | `True` |
| `CSRF_COOKIE_SECURE` | Secure CSRF cookie | `True` |

## Troubleshooting

### Build Fails
- Check that all dependencies are in `requirements.txt`
- Ensure `Dockerfile` is in the `backend/` directory
- Check build logs in Render dashboard

### Database Connection Issues
- Verify database environment variables are set correctly
- Check that the database is running
- Ensure `USE_POSTGRESQL=True` is set

### Static Files Not Loading
- Run `python manage.py collectstatic` in Render shell
- Check `STATIC_ROOT` in settings
- Verify `STATIC_URL` is set correctly

### Application Crashes
- Check application logs in Render dashboard
- Verify all environment variables are set
- Run `python manage.py check` in shell

## Monitoring

- **Logs**: Available in Render dashboard under "Logs" tab
- **Metrics**: Available in Render dashboard under "Metrics" tab
- **Health Check**: Render automatically monitors your service

## Scaling

To scale your application:
1. Go to your web service in Render dashboard
2. Click "Settings"
3. Under "Instance Type", select a larger plan
4. Click "Save Changes"

## Custom Domain

To add a custom domain:
1. Go to your web service in Render dashboard
2. Click "Settings"
3. Under "Custom Domains", click "Add"
4. Enter your domain name
5. Update your DNS records as instructed
